Image Edit Eval Survey

聚焦：text-guided / instruction-based image editing 的评估、metric、benchmark、reward modeling。
目标：把“怎么评”和“怎么把评估转成 reward 设计”统一到一份可读的 survey 里。
说明：这是一个 survey 草稿型 HTML，不是论文最终版。当前内容基于已核实的公开论文原文/摘要锚点整理，重点放在：问题背景、时间线、评测方法与指标、方法对比、发展趋势、问题与 reward 启发。

1. 问题背景

图像编辑的核心不是单纯生成一张“好看”的图，而是同时满足：

  • instruction following / editing alignment：按指令改对；
  • preservation：未要求改的内容别乱变；
  • perceptual quality：结果自然、无伪影；
  • task-specific consistency：如身份、结构、版式、动作、商品 logo 等专用一致性。

传统单一指标很难同时覆盖这些目标，因此近年来评估方法开始从 CLIP / LPIPS / SSIM 走向 LLM/MLLM judges、mask-aware metrics、QA-based evaluation 和 reward models。

2. 时间线

2022–2023：早期标准化 benchmark 与 human study

这一阶段主要关注如何建立可比较的基准、引入人类评分、以及用 CLIP / VLM 做自动评估。

代表：EditBench、EditVal、MagicBrush、MGIE。

2024：开始系统讨论 preservation / modification 平衡

这一阶段出现了明确批评：单纯 CLIPScore 偏向 modification，而全图相似度偏向 preservation。

代表：AugCLIP、BPM、GIE-Bench。

2025：LLM/MLLM judge、reward model、human-aligned benchmark 成为主流

这一阶段的重点是把图像编辑评分做得更细粒度、更人类对齐，并服务于 RL / reward learning。

代表：TIEdit、LMM4Edit、Human-Aligned MLLM Judges、EditScore、MotionEdit。

3. 评测方法与指标总览

方法家族 典型指标 / 形式 优点 主要问题
传统图像质量 / 相似度 LPIPS、SSIM、PSNR、FID、IS、CLIPScore 简单、便宜、易复现 难同时判断“改对了没有”和“该保留的保住没有”
VLM / LMM judge GPT-4V / GPT-4o / Gemini / Qwen-VL / GPT-5-mini 等 能同时理解图、文、变化 成本高、稳定性受 prompt 影响、细粒度几何可能不稳
mask-aware / region-aware 编辑区域定位 + 区域内修改分 + 区域外保持分 能区分该改与不该改 依赖区域定位；没有 mask 时更复杂
QA / VQA-style 自动生成问题，判断功能正确性 可解释、可自动化、易与 human study 对齐 问题生成质量影响评估可靠性
reward model / RL reward scalar score、pairwise preference、rank-based reward 可直接用于优化 reward 设计难，易偏某一侧
task-specific consistency ArcFace、OCR、pose estimator、optical flow 等 适合专用任务 不通用，跨任务可迁移性有限

4. 原文锚点：每种方法在讲什么

4.1 TIEdit / Evaluating Image Editing with LLMs

“reliable assessment should simultaneously consider perceptual quality, alignment with textual instructions, and preservation of original image content.”
“15,360 mean opinion scores (MOSs) across three evaluation dimensions: perceptual quality, editing alignment, and content preservation.”

解读：TIEdit 把图像编辑评分明确拆成三轴，是一类非常适合作为 reward 设计模板的 benchmark。

4.2 LMM4Edit

“EBench-18K includes 1,080 source images with corresponding editing prompts across 21 tasks, 18K+ edited images produced by 17 state-of-the-art TIE models, 55K+ mean opinion scores (MOSs) ... and 18K+ question-answering (QA) pairs.”
“LMM4Edit, a LMM-based metric for evaluating image Editing models from perceptual quality, editing alignment, attribute preservation, and task-specific QA accuracy in an all-in-one manner.”

解读：LMM4Edit 强调“多维度 + QA”，适合把 reward 从单分数扩展成可解释多维分数。

4.3 Human-Aligned MLLM Judges

“decomposes common evaluation notions into twelve fine-grained interpretable factors spanning image preservation, edit quality, and instruction fidelity.”
“traditional image editing metrics are often poor proxies for these factors, failing to distinguish over-edited or semantically imprecise outputs...”

解读：与其把评分压成一个黑盒总分，不如拆成多个可解释因子，先定位再聚合。

4.4 EditScore / EditReward-Bench

“the lack of a high-fidelity, efficient reward signal.”
“EditScore takes (Instruction, Input Image, Output Image) as input, (Reasoning, Scalar Score) as output.”
“Semantic Consistency (SC) ... ensuring specified objects are correctly modified while unmentioned regions remain preserved.”
“Perceptual Quality (PQ) ... focusing on photorealism and the absence of artifacts. The final score is the geometric mean of the SC and PQ scores.”

解读：这是最接近“怎么把评估做成 reward”的路线。SC 负责改对，PQ 负责别改坏。

4.5 BPM / Balancing Preservation and Modification

“explicitly disentangling the image into editing-relevant and irrelevant regions for specific consideration.”
“Region-Aware Judge evaluates whether the position and size of the edited region align with instruction, and Semantic-Aware Judge further assesses the instruction content compliance within editing-relevant regions as well as content preservation within irrelevant regions...”

解读：这条路线最适合解决“preservation reward 难给”的问题，因为它直接把 reward 拆成 region-level 和 semantic-level 两层。

4.6 AugCLIP / Preserve or Modify?

“existing metrics have a context-blindness problem... biasing towards either modification or preservation.”
“CLIPScore ... tends to favor modification and ignore core attributes to be preserved”
“AugCLIP ... balances preservation and modification by estimating the representation of an ideal edited image that aligns with the target text with minimum alteration on the source image.”

解读：单一指标会偏。reward 设计必须显式建模 preserve vs modify 的 trade-off。

4.7 GIE-Bench

“functional correctness, assessed via automatically generated multiple-choice questions...”
“image content preservation, which ensures that non-targeted regions of the image remain visually consistent using an object-aware masking technique and preservation scoring.”
“we compute the mean squared error between the original and edited images over unmasked regions ... after applying geometric alignment.”

解读：这是一个很实用的“VQA + mask 外保留”范式，尤其适合局部编辑。

4.8 MotionEdit

“For discriminative evaluation, we ... comparing the optical flow ... between the input and model-edited images against the input–ground truth flow.”
“For generative evaluation, we adopt Multimodal Large Language Model (MLLM)-based metrics to assess the fidelity, preservation, coherence, and overall quality of edited images.”
“our reward function must quantify the alignment between model-predicted motion and the ground-truth motion edit.”

解读：optical flow 是 motion editing 的专用一致性 reward，不是通用 reward；它对动作/姿态类编辑有效，对属性/风格类编辑不适用。

6. 发展趋势

  • 从单分数走向多维分数：quality、alignment、preservation、QA accuracy 分开看。
  • 从纯自动指标走向人类对齐：MOS、pairwise preference、human-validated benchmark 越来越多。
  • 从全图评估走向区域级评估：editing-relevant / irrelevant regions 被明确区分。
  • 从评估模型走向 reward model：不仅要“测”，还要“可用于 RL 训练”。
  • 从通用指标走向任务专用指标：人脸、文档、商品、动作、版式等都开始有专门一致性信号。
  • 从静态编辑走向动态编辑：motion / consistency / geometry 的专用评估开始出现。

7. 存在的问题

  • 指标之间互相冲突：改对和保留经常天然冲突。
  • 全图指标不够细：难识别 over-edit / under-edit / irrelevant-region drift。
  • LMM judge 成本较高：不适合超大规模在线训练时直接全量使用。
  • 不同任务差异大：通用 reward 不能覆盖人脸、商品、文档、motion 等所有场景。
  • 人类偏好仍是最终标准：自动指标和人类判断仍有 gap。

8. 对 reward 设计的启发

从这些论文里可以得到一个较稳的原则：reward 不能只看“输出图好不好”，而要同时看“改对了吗、保住了吗、自然吗、任务专用一致吗”。

建议的 reward 结构：
R = instruction reward + target edit reward + non-target preservation reward + quality reward + task-specific reward
reward 项可借鉴方法落地建议
instruction rewardTIEdit、EditScore、GIE-Bench用 VLM / VQA 判断目标是否完成
target edit rewardBPM、AugCLIP先定位编辑区域，再评语义修改是否正确
non-target preservationBPM、GIE-Bench、TIEditmask 外区域用 region-aware consistency 评分
quality rewardTIEdit、LMM4Edit、EditScore用 perceptual quality / artifact / realism
task-specific rewardMotionEdit、Human-Aligned Judges按任务加入身份/结构/motion/OCR 等专用项
一个实用的聚合例子： R_inst = VLM/Judge 对指令完成度的评分 R_edit = 目标区域修改正确性的评分 R_pres = 非目标区域保持一致性的评分 R_qual = 图像质量 / 伪影惩罚 R_task = 身份 / OCR / motion / layout 等任务项 R_total = w1*R_inst + w2*R_edit + w3*R_pres + w4*R_qual + w5*R_task 更稳的做法： - 对 R_inst 或 R_edit 设门槛，失败时整体分数不能太高 - 对 R_pres 设上限惩罚，避免过度修改 - 在 motion / face / document 等任务上加入 task-specific reward

9. 建议的 survey 结论段

可以用下面这段作为最终总结思路：

图像编辑评估正在从单一图文相似度，转向多维、细粒度、可解释且与人类偏好对齐的综合评估。未来更有前景的方向不是寻找一个万能指标，而是构建“任务理解 + 区域分解 + preservation / modification 平衡 + 任务专用 consistency”的组合式 reward 与 benchmark 体系。
