MagicBrush

2023 · instruction-guided image editing 数据集 / benchmark
链接
arXiv · Dataset
一句话定位
MagicBrush 是人工标注的真实图像编辑数据集，包含原图、编辑指令和目标图，常用于训练和评测 instruction-guided image editing 模型。

怎么评

  • 使用 source image、instruction、target image 三元组。
  • 可评估指令执行、目标图匹配、编辑质量与多轮编辑能力。
  • 常作为局部/真实图像编辑 benchmark。

创新点

  • 人工构造高质量编辑前后对，而不是纯合成 prompt。
  • 支持更真实的 instruction editing 评估。

局限

  • 单独使用时，对 reward 的维度拆分不如 TIEdit/LMM4Edit 明确。
  • 需要额外设计 preserve/quality 分项。

对 reward 设计的启发

适合作为 supervised / preference 数据来源，source-target pair 可以用于 target edit reward 与 preservation reward 的监督。
