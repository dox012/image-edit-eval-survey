Text-to-Image Evaluation Survey

补充视角：先梳理文生图评估怎么做，再对比图像编辑评估多出来的问题。
核心结论：文生图评估主要解决 text prompt → generated image 的 prompt following / image quality；图像编辑评估则是 source image + instruction → edited image，因此额外需要评 source preservation、target-region modification、before-after consistency 和 over-edit/under-edit。

1. 文生图评估主要评什么

  • 图文一致性 / prompt following：物体、属性、数量、空间关系、动作、场景、风格是否符合 prompt。
  • 组合泛化：多对象组合、属性绑定、对象关系、counting、3D spatial relation、复杂长 prompt。
  • 图像质量：photorealism、aesthetics、artifacts、diversity。
  • 人类偏好：pairwise preference、rating、ranking，并训练 reward / scorer。
  • 可解释自动评估：VQA / detection / MLLM judge，把整体图文一致性拆成问题或对象级检查。

2. 时间线

时间代表方法评估范式意义

3. 代表论文 / benchmark

年份论文 / Benchmark类型核心贡献适合评什么
2022DrawBench / Imagen人工偏好 + prompt benchmarkImagen 论文引入 DrawBench，用一组挑战性 prompt 对 text-to-image 模型做 side-by-side 人工偏好比较，强调语言理解和复杂描述生成能力。适合作为 qualitative / human preference benchmark，但自动化指标较少。
2022PartiPrompts (P2)1600+ prompt benchmarkPartiPrompts 是 Parti 论文提出的 1600+ 英文 prompts，覆盖类别、难度、风格、世界知识和复杂组合，用于横向观察 T2I 模型能力。适合人工横评和 case study，但不是细粒度自动判分框架。
2023TIFAQA-based faithfulness metricTIFA 把 prompt 自动分解为 question-answer pairs，再用 VQA 模型检查生成图是否能回答这些问题。TIFA v1.0 包含 4K text inputs 和 25K questions。可解释、细粒度、reference-free，适合 text-image faithfulness。
2023GenEvalobject-level alignmentGenEval 用目标检测和视觉模型评估 object co-occurrence、count、color、position、color attribution 等对象级组合属性。比 CLIPScore 更适合 object-level compositional alignment。
2023/2025T2I-CompBench++compositional benchmarkT2I-CompBench++ 包含 8K compositional prompts，覆盖属性绑定、对象关系、数量、3D 空间关系和复杂组合。强调复杂组合生成能力，用检测、VQA、MLLM 等多种指标评估。
2023ImageRewardhuman preference reward modelImageReward 通过 137K expert comparisons 训练通用 T2I human preference reward model，可用于自动评估和 ReFL 优化。把 T2I 评估推进到 reward learning。
2023Pick-a-Pic / PickScoreuser preference dataset / scorerPick-a-Pic 收集真实用户对 T2I 输出的偏好，训练 PickScore，用于预测人类偏好和评估模型。偏好数据规模大，适合 reward/preference learning。
2024VQAScoreVQA-based alignment scoreVQAScore 将文本对齐转化为 “Does this figure show {text}?” 的 VQA yes-probability，缓解 CLIP bag-of-words 问题。简单、通用，可跨多个 image-text alignment benchmark 使用。
2024+DPG-Benchdense prompt / complex prompt benchmarkDPG-Bench 代表更复杂、更长 prompt 的 T2I 评估方向，关注模型对 dense prompt 中多对象、属性和关系的遵循。适合观察现代模型在长指令和复杂组合下的 prompt following。
2024+DOCCI / RealQA / AIGC-IQA描述质量 / 真实图像质量补充集这类数据更偏图文描述、真实图像质量或 AIGC 图像质量评价，可为 T2I eval 中的 caption fidelity、quality/aesthetics 维度提供补充。不一定是专门的 T2I benchmark，但可作为 quality/fidelity 评估资源。

4. 评测方法分类

方法家族典型代表优点局限
分布级质量指标FID、IS便宜，适合整体图像分布质量比较不能判断单张图是否符合 prompt；对复杂语义无能为力
图文 embedding 相似度CLIPScorereference-free，容易大规模跑bag-of-words 问题明显，难判断关系、数量和属性绑定
人工偏好DrawBench、PartiPrompts、Pick-a-Pic最接近真实用户感受成本高，不易频繁评估
VQA / QA-basedTIFA、VQAScore可解释，能拆成对象、属性、关系问题依赖问题生成和 VQA 模型可靠性
Detection-basedGenEval、T2I-CompBench适合对象出现、数量、位置、颜色等可检测属性受 detector 类别范围和检测精度限制
Reward / preference modelImageReward、PickScore可直接用于排序、筛选和优化模型容易学习偏好偏置，需防 reward hacking
MLLM judgeGPT-4V/GPT-4o、Qwen-VL 等通用、能读复杂 prompt 与图像成本高，prompt 和模型版本影响稳定性

6. 对图像编辑 reward 设计的启发

文生图 reward 通常可以写成：

R_T2I = w_align * R_text_image_alignment + w_quality * R_image_quality + w_pref * R_human_preference

但图像编辑至少需要：

R_Edit = w_inst * R_instruction_alignment + w_target * R_target_modification + w_preserve * R_source_preservation + w_quality * R_visual_quality + w_task * R_task_specific_consistency
关键区别：TIFA / GenEval / T2I-CompBench 这类 T2I 指标可以迁移到 image editing 的 instruction alignment 和 output quality 部分，但不能单独解决 source preservation 和 before-after consistency。因此 image edit eval 不能只用 CLIPScore、TIFA 或 GenEval；必须加入 source-aware / region-aware / task-specific consistency reward。
