EditScore / EditReward-Bench

2025 · 图像编辑 reward model / benchmark
链接
arXiv · Code
一句话定位
EditScore 是最接近“评估如何变成 reward”的工作之一，输入 instruction、input image、output image，输出 reasoning 与 scalar score，并提出 EditReward-Bench。

怎么评

  • Semantic Consistency：指定对象是否正确修改、未提及区域是否保持。
  • Perceptual Quality：真实感、无伪影、视觉质量。
  • 最终分数用 SC 和 PQ 聚合。

创新点

  • 把 judge 形式直接设计成 reward signal。
  • reasoning + scalar score 兼顾可解释性与可优化性。

局限

  • 在线 RL 中要防止 reward hacking。
  • 不同编辑类型的 SC/PQ 权重可能需要动态调整。

对 reward 设计的启发

可直接借鉴：R = geometric_mean(SC, PQ)，并保留 textual reasoning 做调试。
