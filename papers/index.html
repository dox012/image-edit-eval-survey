Paper Notes

Survey 中相关论文/benchmark 的逐篇子页面。

年份论文 / Benchmark类型定位
2022EditBench编辑评测 benchmarkEditBench 是早期用于评估 text-guided / mask-based image editing 的 benchmark，重点在于用标准化输入、目标文本和编辑任务来比较不同编辑模型。
2023EditVal图像编辑评测 benchmarkEditVal 面向 text-guided image editing 的系统评估，覆盖多类编辑任务，用于比较编辑模型是否能准确执行指令。
2023MagicBrushinstruction-guided image editing 数据集 / benchmarkMagicBrush 是人工标注的真实图像编辑数据集，包含原图、编辑指令和目标图，常用于训练和评测 instruction-guided image editing 模型。
2023MGIEMLLM-guided image editing 方法 / 评测基线MGIE 使用 multimodal large language model 辅助理解和重写编辑指令，是 MLLM 参与图像编辑和评估的代表性早期工作之一。
2025/2026TIEdit / Evaluating Image Editing with LLMs三维 MOS 图像编辑评估 benchmarkTIEdit 直接讨论图像编辑评估应同时考虑 perceptual quality、editing alignment 和 content preservation，是 reward 设计里最清晰的三轴模板之一。
2025LMM4EditLMM-based 图像编辑评价模型 / EBench-18KLMM4Edit 构建 EBench-18K，并训练/提出一个 LMM-based metric，从 perceptual quality、editing alignment、attribute preservation 和 task-specific QA accuracy 综合评价图像编辑。
2025/2026Human-Aligned MLLM Judges人类对齐 MLLM judge / 12 因子评估该工作把图像编辑评估拆成 12 个可解释因子，覆盖 image preservation、edit quality 和 instruction fidelity，目标是让 MLLM judge 更接近人类判断。
2025EditScore / EditReward-Bench图像编辑 reward model / benchmarkEditScore 是最接近“评估如何变成 reward”的工作之一，输入 instruction、input image、output image，输出 reasoning 与 scalar score，并提出 EditReward-Bench。
2025BPM / Balancing Preservation and Modificationpreservation-modification 平衡评价BPM 重点解决图像编辑中的 preserve vs modify 平衡，通过 region-aware judge 和 semantic-aware judge 区分编辑相关区域与无关区域。
2024AugCLIP / Preserve or Modify?preserve-modify 平衡指标AugCLIP 指出传统指标存在 context-blindness：CLIPScore 倾向鼓励修改，全图相似度则倾向保留，因而提出更平衡的编辑评估方式。
2025GIE-Benchgrounded image editing benchmarkGIE-Bench 面向 grounded evaluation for text-guided image editing，包含高质量编辑样例、详细指令、evaluation questions 和 object masks。
2025/2026MotionEditmotion-centric image editing benchmark / rewardMotionEdit 专注 motion-centric image editing：修改主体动作和交互，同时保持身份、结构和物理合理性。它的 optical-flow reward 是动作编辑专用的一致性信号。
