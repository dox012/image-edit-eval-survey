一、全文核对后的结论

  • MotionEdit 不是单纯评图文一致性，而是把“编辑前后两图的一致性”写进任务定义和评测设计里。
  • 它的目标不是“只看文本有没有对上”，而是要同时满足：motion change、preservation of non-edited factors、identity / structure / physical plausibility。
  • 它的评测不靠 DINOv2 / LPIPS 这类通用保真指标，而是采用：
    • generative metrics：Fidelity / Preservation / Coherence / Overall
    • discriminative metric：基于 optical flow 的 MAS
    • preference-based metric：pairwise win rate
  • 训练侧的 reward 也不是单一 VLM reward，而是 optical-flow motion reward + MLLM reward 的组合。

三、MotionEdit 的“编辑前后两图一致性”到底怎么做

全文里，MotionEdit 的一致性不是“算原图和结果图越像越好”，而是“该动的动，不该动的尽量不动”。它明确把 consistency 拆成以下几类：

  • non-edited factors consistency：appearance / background / viewpoint 保持一致
  • identity preservation：主体身份保持
  • structure / geometric consistency：姿态、结构、几何对齐正确
  • physical plausibility：动作在物理上合理

换句话说，它评的不是“图文一致性 alone”，而是“motion change + preservation”的联合目标。

四、全文核实后，对原表中 MotionEdit 相关条目的修订

  • 原先如果把 MotionEdit 仅写成“评图文一致性”是不准确的；应改成“明确评 motion edit 的两图一致性 / preservation / identity / structure”。
  • 原先如果写“它用 DINOv2/LPIPS 做 preservation reward”是不对的；全文没有这个做法。它的 reward 是 optical-flow-based motion reward。
  • 原先如果说“它只看 benchmark 总分”也不完整；它同时有 generative、discriminative、preference-based 三类评测。

六、和图文一致性的关系，全文核实后更准确的说法

  • 图文一致性：主要看编辑结果有没有按 instruction 改对。
  • MotionEdit 的两图一致性：不仅看改对没有，还看原图里不该动的 appearance / background / viewpoint / identity 有没有保住。
  • MotionEdit 的实现方式不是把两图一致性降成简单像素距离，而是用 optical flow 去衡量 motion 变化是否和 ground truth 一致。
一句话总结：MotionEdit 这篇论文的核心不是“图文一致性评测”，而是“motion editing 下的编辑前后两图一致性 + preservation + identity/structure consistency”，并且它把这件事真正落实到 benchmark、human eval 和 reward 里了。
